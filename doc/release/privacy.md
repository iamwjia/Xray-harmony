# 隐私说明与权限清单（草稿，待你确认后定稿）

适用版本：Tunnelix（`com.tunnelix.app`），HarmonyOS NEXT API 26。
本文分三部分：**给用户看的隐私说明**、**给审核看的权限清单**、**数据流事实表**（每条都能在代码里找到出处）。

---

## 一、隐私说明（用户可读版）

### 我们不收集你的数据

Tunnelix 不收集、不上报、不出售任何个人信息。应用内**没有**统计 SDK、崩溃上报 SDK、
广告 SDK，也没有账号体系。你不需要注册或登录。

### 应用会接触哪些数据，为什么

| 数据 | 什么时候 | 去了哪里 | 存在哪里 |
|---|---|---|---|
| 你添加的节点信息（地址、端口、协议、备注） | 你手动添加/导入时 | **不发送**，只本机使用 | 本机应用沙箱（`preferences`） |
| 节点凭据（UUID / 密码 / shadowsocks 口令） | 同上 | **不发送**，只交给本机内核 | 系统安全存储（HUKS 加密），不落明文 |
| 订阅地址（可能含 token） | 你添加订阅时 | 只在你点「更新」时访问**你自己填的那个地址** | 系统安全存储（HUKS 加密） |
| 分流用的 geoip/geosite 数据 | **只有你点「联网更新」时** | 访问 GitHub 上的 v2fly 官方发布 | 本机应用沙箱 |
| 运行日志 | 应用运行期间 | 不发送 | 本机应用沙箱（最多 500 条，写入时脱敏） |
| 备份文件 | 你点「导出」时 | 只写到**你选择的**位置 / 或交给系统分享面板 | 由你决定放哪 |
| 网络流量（代理内容） | 你连接时 | 经你配置的节点转发 | **不记录**（应用不保存任何流量内容） |

### 关于「VPN 权限」

代理功能需要建立系统级 VPN 连接。**首次连接时系统会弹出授权框，必须你本人点允许**，
应用无法绕过。授权后，本应用的流量转发只在你的设备内完成，不经过任何第三方服务器。

### 关于剪贴板

应用**从不读取**剪贴板。导入节点时，是你自己在输入框里粘贴（粘贴动作由系统处理），
应用只拿到输入框里的文字。应用会**写入**剪贴板（复制代理地址、复制口令、复制分享链接），
且只在你明确点击复制时发生。

### 关于日志

日志默认只记录连接状态、错误原因等诊断信息，**写入时就已脱敏**：UUID、分享链接、
密码类字段会被替换成 `****`。日志只在本机缓冲（上限 500 条），导出由你主动触发。

### 你的控制权

- 随时删除单个节点、订阅、分流规则；
- 「设置 → 清空数据」会删除节点、凭据、订阅、规则、日志与探针记录（**含安全存储里的凭据**），不可恢复；
- 卸载应用即删除应用沙箱内全部数据。

## 二、权限清单（审核用）

在 `entry/src/main/module.json5` 中声明的权限**只有一项**：

| 权限 | 声明位置 | 用途 | 是否敏感 | 拒绝后的行为 |
|---|---|---|---|---|
| `ohos.permission.INTERNET` | `module.requestPermissions` | 连接你配置的代理节点、更新订阅、下载分流数据 | 普通权限（normal） | 应用无法工作，属必需 |

**没有声明、也没有申请的权限**（重要，避免误判为"后台偷偷用"）：

- 定位、通讯录、短信、通话记录、相机、麦克风、相册：**均未申请**
- 通知：未申请（应用不发通知）
- 剪贴板读取：未申请（应用只写不读）
- 读取/写入公共目录：**未申请**——所有文件操作都通过系统文件选择器（picker），
  由用户自己指定文件，应用只拿到该文件句柄

### VPN 能力不是普通权限

代理功能通过 `extensionAbilities` 中 `type: "vpn"` 的扩展能力实现（`MyVpnExtAbility`），
不是通过 `requestPermissions` 申请。用户首次连接时由系统弹窗授权，**每次授权范围由系统决定**，
应用侧无法静默开启。这一点在审核时容易被误认为"缺少 VPN 权限声明"，特此说明。

## 三、数据流事实表（代码出处）

| 事实 | 代码依据 |
|---|---|
| 仅声明 INTERNET 权限 | `entry/src/main/module.json5` → `requestPermissions`（1 项） |
| 无统计/埋点 SDK | 全仓 `grep -ri "analytics\|umeng\|bugly\|oaid\|getUdid"` = 0 命中 |
| 不读剪贴板 | `pasteboard` 仅出现 `setData`（4 处），无 `getData` |
| 凭据存 HUKS，不落明文 | `platform/SecretStore.ets`（Asset Store / HUKS）+ `ConfigService.ensureSecureMigration()` 一次性迁移 v1 明文 |
| 订阅地址加密存储 | `service/SubscriptionStore.ets` 的 `urlRef` 只存引用，明文在 SecretStore |
| 日志写入即脱敏 | `platform/Logger.ets` + `tests/log-redaction.test.js`（UUID / 分享链接 / 密码类字段） |
| 日志上限 500 条 | `service/EventLog.ets` / `Logger` 的环形缓冲 |
| 联网只发生在两处 | `service/GeoAssets.ets`（仅点「联网更新」触发）、`service/SubscriptionService.ets`（仅点「更新订阅」触发） |
| 备份内容整体加密 | `platform/BundleCrypto.ets`（PBKDF2-SHA256 + AES-256-GCM，随机 salt/nonce） |
| 不保存流量内容 | 全仓无流量落盘逻辑；转发层只搬字节（`vpnability/VpnExtAbility.ets` → `Forwarding`） |
| 明文凭据用完即弃 | `VpnExtAbility.dropSessionSecrets()`（本轮新增） |

## 四、待你确认的三点

1. **隐私说明放在哪**：应用内加一页（像「开源许可」那样），还是只作为 AGC 商店页的隐私政策链接？
   （AGC 通常要求有可访问的隐私政策 URL；如果要 URL，需要你把它放到某个可公开访问的地方，比如仓库的 `doc/release/privacy.md` raw 链接。）
2. **是否需要"首次启动同意隐私政策"的勾选**：当前应用**没有**这个流程。国内上架一般要求首启弹窗 + 勾选，
   而 HarmonyOS 应用市场对网络类应用通常会查。这是我建议补的功能（需要你确认要不要做）。
3. **数据保留期的表述**：上面写的是"卸载即删除"。如果后续加了云同步/分享导出，这句要改。
