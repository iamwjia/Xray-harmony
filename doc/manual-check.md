# 手动验收清单

> 自动化跑不到的东西都在这里。**每条都有判据**，勾选时只看判据，不看“感觉差不多”。
> 三类标记：
> - `[脚本]` 一键验证已覆盖，不用手点（`powershell -File scripts\verify.ps1`）
> - `[设备]` 必须在模拟器/真机上点或看
> - `[人眼]` 必须有人看画面（截图后自己判断，Agent 看不到图）

## 1. 触摸交互 `[设备]`

判据统一是：**手指按下后 100ms 内必须有可见变化**；没有变化 = 退回“鼠标式”设计。

- [ ] **节点行按下** → 底色变化（未选中变灰 `bg_chip`，选中变浅蓝 `accent_subtle`），抬起恢复
- [ ] **订阅行按下** → 同上；且同一时刻只有一行变色
- [ ] **分组 chip / 日志级别 chip** → 有系统按钮的回弹/变暗
- [ ] **导入框输完按回车** → 直接开始导入，不需要去点被键盘挡住的按钮
- [ ] **添加规则输入框回车** → 直接添加
- [ ] **备份口令框回车** → 导出/恢复开始
- [ ] **首页代理地址长按 500ms** → 出现「已复制」，剪贴板内容严格等于 `127.0.0.1:<port>`
- [ ] **日志页诊断行长按** → 同上
- [ ] **设置页「每6/12/24小时/每周」** → 窄屏下换行，不被压扁或截断
- [ ] **节点操作菜单** → 宽度约 180vp，五项完整可读（编辑/测连通性/上移/下移/删除），首行「上移」灰、末行「下移」灰

## 2. 数据与状态 `[设备]`

- [ ] **重启不丢数据**：加节点 → 强制停止 → 重启 → 节点仍在（`nodeStore load: rawLen>0`）
- [ ] **首次明示只弹一次**：确认后重启，点连接不再弹
- [ ] **清空数据**：设置 → 清空 → 重启后节点 0、规则 0、明示重新出现
- [ ] **备份→恢复**：导出 → 清空 → 恢复 → 节点回来；**错误口令必须失败**
- [ ] **删除订阅不删节点**：确认弹窗写清“节点保留”，删后节点数不变
- [ ] **节点连通性**：菜单「测连通性」→ 提示条给出「可达 N ms」或具体不可达原因

## 3. 数据面（必须真机）`[设备]`

- [ ] **`202` 是否消失**：点连接 → 状态文件 `vpn_state.json` 里不再是
      `{"state":"error","code":202,"msg":"Non-system applications use system APIs"}`
      （这是决定产品可行性的一条）
- [ ] **转发生效**：连接后从设备访问外网域名成功；服务端日志出现 `connection opened`（`accepted` 不算）
- [ ] **DNS 走隧道**：`tcpdump` 观察 53 端口流量走 tun，而不是本地直连
- [ ] **断开顺序**：断开后 tun 已销毁、无残留（`ip link` 里没有 vpn-tun）
- [ ] **失败注入**：把 socks 端口改错 → 状态进入 `error`，且 **tun 已被销毁**（不留黑洞）

## 4. 深色模式 `[人眼]`

每页截一张深色图，只看四件事：**有没有白块、文字是否可读、选中态是否可辨、横幅是否刺眼**。

- [ ] 节点列表（选中行 / 空态 / 分组 chip）
- [ ] 节点编辑（输入框边界）
- [ ] 分流规则
- [ ] 运行日志
- [ ] 设置
- [ ] 订阅管理
- [ ] 备份与恢复
- [ ] 开源许可

## 5. 文案与诚实性 `[人眼]`

- [ ] 首页不出现 `SOCKS` / `freedom` / `内核直连` 等实现词（`DevPanel` 豁免）
- [ ] 首页明确显示「系统 VPN：已接管 / 未接管 —— 原因」
- [ ] 连接失败时给的是人话（不是 `202` 裸码）
- [ ] 长按类功能都有可见提示，不只在读屏里

## 6. 一键验证覆盖了什么 `[脚本]`

```
① 配置生成测试（跑 KernelConfigBuilder 真实函数体）
② lastEndpoint 结构测试
③ 日志脱敏测试（跑 Logger.redact 真实函数体）
④ 文字闸门：可换行 Text 必须有 lineHeight
⑤ 编码闸门：文本必须 UTF-8、无 mojibake、.ps1 必须带 BOM
⑥ 行尾闸门：跟踪文件必须 LF
⑦ arm64 编译（ArkTS 全量类型检查）
```
